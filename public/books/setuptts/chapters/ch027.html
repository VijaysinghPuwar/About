20 What to Learn Next

These subjects are ordered by how much they would deepen your understanding of this particular codebase. Each lists what to study and where in SetupTTS to apply it.

  1. Python async programming. Coroutines, tasks, await, async generators, asyncio.wait_for, cancellation semantics and CancelledError, call_soon_threadsafe. Then re-read _synthesise_attempt and TTSWorker.cancel until every line is obvious.
  2. The asyncio event loop itself. How a loop schedules callbacks and waits on sockets (selectors versus Windows’ Proactor), and why a loop belongs to one thread. This explains the “one loop per QThread” design.
  3. PySide6 and Qt architecture. The object tree and ownership, the event loop, signals and slots, connection types, QThread and thread affinity, layouts and size policies, stylesheets. Apply it to JobQueue._start_job and MainWindow._apply_responsive_layout.
  4. HTTP, TLS and WebSockets. The HTTP Upgrade handshake, WebSocket text and binary frames, certificate chains and trust stores, proxies and CONNECT tunnels. Apply it to edge-tts’s __stream and build_ssl_context.
  5. How neural TTS works. Text normalisation, phonemes and prosody, acoustic models and neural vocoders, and why sentence-level metadata exists. This explains why text cleanup and sentence boundaries matter so much here.
  6. Digital audio and MP3. Sampling, bit rate, constant versus variable bit rate, MPEG frames and headers, ID3 tags. Then read mp3_duration.py; you should be able to derive “144 bytes per frame” yourself.
  7. Distributed-systems reliability. Partial failure, timeouts as failure detectors, at-least-once versus exactly-once, idempotency. Apply it to why retrying a chunk is safe (nothing is saved until an attempt fully succeeds).
  8. Retry and back-off strategies. Exponential back-off, jitter, retry budgets, circuit breakers. Compare them with _process_chunk and _RollingHealthState, which is a simple circuit-breaker cousin.
  9. State persistence and crash consistency. Atomic rename, fsync and what it guarantees, write-ahead logging, SQLite’s WAL mode and user_version migrations. Apply it to _atomic_write_bytes and HistoryService.
  10. Python packaging and PyInstaller. Wheels, pyproject.toml, how PyInstaller’s analysis and hooks work, onefile versus onedir, data files and _MEIPASS. Apply it to both spec files.
  11. CI/CD with GitHub Actions. Triggers, jobs and needs, runners, artifacts, permissions, concurrency groups, release actions. Then extend build.yml with a pull_request trigger that only runs the tests.
  12. Cross-platform desktop development. Platform conventions for data folders, code signing and notarisation, installers, file locking and path rules on Windows. The project’s next step here would be signing the macOS app and Windows installer.
