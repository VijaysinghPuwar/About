The two splits are QSplitters: a horizontal one between editor and sidebar, and a vertical one between that row and the history strip. Menus provide File (Open, Generate, Settings, Quit), Edit (Clear Text), View (Show Recent Conversions) and Help (Open Logs Folder, About). Shortcuts use Ctrl, which Qt maps to Cmd on macOS.

5.2 The panels

5.2.1 InputPanel: the editor

app/ui/panels/input_panel.py is a QTextEdit with plain-text paste, a word and character counter, and drag-and-drop for .txt and .md files. It emits two signals deliberately:

  • has_text_changed(bool) fires immediately on every edit, but only when emptiness changes. It is cheap and drives the Generate button.
  • text_changed(str) fires after a 250 ms settle timer. It drives the word count and the voice-compatibility check, both of which scan the whole document. Before this split, typing in a 150,000-character book lagged on every keystroke.

flush() delivers a pending change at once, and MainWindow.get_input_text() calls it before Generate reads the text, so nothing typed in the last quarter second is lost.

File import is more careful than it looks. decode_text_file (input_panel.py:46-93) treats a byte-order mark as authoritative; uses NUL-byte positions to recognise UTF-16 without a BOM; tries strict UTF-8; then tries legacy code pages in a deliberate order (the system’s own code page, then cp932 Shift-JIS and EUC-KR, BOM-less UTF-16 Chinese or Japanese, cp1252, cp1251 Cyrillic, GB18030, Big5 and finally cp1250), accepting each only if the result is plausible for its script. Files over 50 MB are refused as “almost certainly not prose”. Clear Text deletes through a text cursor instead of calling clear(), so Undo still works.

5.2.2 OutputPanel: the controller

app/ui/panels/output_panel.py is the largest UI file because it is the controller as well as the sidebar. Its sections:

  • Voice. Search (debounced 150 ms), language and gender filters, the voice combo box, and Preview Voice. Recently used voices appear first under a disabled “Recently Used” header. Voices are labelled by persona, keeping the multilingual variant visible: en-US-AndrewMultilingualNeural becomes “Andrew (Multilingual)” (app/models/voice.py:6-24). Before v1.6.0 both variants read “Andrew”.
  • Voice guidance. A warning card, with a Use [recommended voice] button, appears when the text’s script or language does not match the voice, or when a multilingual voice is chosen for an English text over 45,000 characters.
  • Speed. A slider from -50 to +100, stored as an integer and converted to edge-tts’s "+5%" format by AppSettings.rate_string().
  • Export. File name and folder with Browse.
  • Resume Unfinished Job. Visible only when resumable staging folders exist; opens a menu to resume or discard each one.
  • Active Jobs. One _JobRowWidget per queued or running job.
  • Generate & Export MP3. Pinned below the scroll area so it is reachable at every window height.

5.2.3 HistoryPanel: recent conversions

A six-column table (When, Text Preview, Voice, Took, Length, File) showing the 50 most recent rows from history.db. Double-click plays the file with the system’s default app; the context menu offers Show in Folder, Copy File Path and Remove from History. Clear All removes rows, never audio files.

5.2.4 Dialogs

Settings (Ctrl/Cmd+,) has four sections: General (default save folder), Voice (the “Auto-match voice to text” option), Logs & Troubleshooting (Open Logs Folder, Open Current Log, Copy Log Path, Copy Diagnostic Info), and About. About shows the version and description.

5.3 How a click reaches the backend

Figure 5.1 shows everything OutputPanel._on_generate (output_panel.py:1145-1277) checks before a job exists. Each failed check stops with a message and queues nothing.

Several of these checks exist because a real problem happened:

  • “A visible voice is selected?” get_selected_voice() falls back to the saved voice when the combo box has no real selection. Before v1.6.2, generating while the voice list was loading, failed or filtered to nothing silently used a voice the user could not see.
  • “Destination is valid?” check_output_path (app/utils/output_paths.py:51-112) refuses characters Windows forbids on every platform (a file named Part 1: Intro.mp3 made on a Mac cannot be copied to a FAT-formatted player), reserved device names such as CON, a missing or unwritable folder (tested by actually creating a temp file, because os.access ignores Windows ACLs), and Windows paths over 240 characters.
  • “File already exists?” The default name is output.mp3 in the last-used folder, so without this question each new job silently replaced the previous audiobook. Keep Both picks name (2).mp3; next_free_path keeps numbers that are part of a real name, so Annual Report (2024).mp3 becomes Annual Report (2024) (2).mp3.

5.4 How the backend reaches the UI

Worker signal JobQueue signal OutputPanel handler Visible effect
progress(int) job_progress(id, pct) _on_job_progress progress bar
stage_changed(kind, text) job_stage_changed _on_job_stage_changed badge and plain stage text
telemetry_updated(JobTelemetry) job_telemetry_updated _on_job_telemetry_updated “Chunk 82 of ~194 · 74 chars/s · about 21 min left”
job_resumable(...) job_resumable(item) _on_job_resumable status message, Resume button refresh
completed(path, s) job_completed(item) _on_job_completed row removed, history row written
failed(msg) job_failed(item) _on_job_failed queued error dialog with Resume / Open Logs

Three presentation choices are worth noticing.

Progress is real. The worker maps characters processed to 3-95 % (_emit_progress_from_chars, tts_worker.py:2597-2602), driven by the sentence-boundary events as audio streams in and corrected to the committed range after each chunk is saved. It only emits when the integer changes, which cut cross-thread signal traffic noticeably on Windows (commit 7bd5fb1). The jump to 100 happens when the file is saved.

Stage text is translated. The worker’s stage strings are technical (“Sending chunk 12/214 to Microsoft (3,412 chars / 3,588 bytes)”). _friendly_stage maps them by prefix to plain phrases such as “Generating audio” or “Finalizing the MP3 file”, and keeps the raw text as a tooltip. The badge colour is neutral grey for LOCAL and REMOTE; amber is reserved for RETRY.

ETA is withheld until it means something. _JobRowWidget._eta_is_reliable hides the time-left estimate until at least chunk 3 and 45 seconds into the job, and _format_eta_words rounds to minutes because second precision “would be false precision”. The speed behind it is an exponential moving average (0.65 * old + 0.35 * new, tts_worker.py:2604-2623).

Error dialogs never stack. Two jobs can fail within a second of each other, and QMessageBox.exec() re-enters the event loop, so a second failure could open a second dialog on top of the first. _failure_dialog_queue shows them one at a time (commit b1dc80f).

5.5 Responsive layout

MainWindow._apply_responsive_layout runs on every resize. It caps the sidebar at 40 % of the window width, sizes the history strip at 20 % of the height (clamped between 88 and 240 px), and keeps the editor row at no less than 55 % of the split. The sidebar has three density levels chosen by window height: comfortable, compact below 760 px (tighter padding), and minimal below 640 px (explanatory hints hidden, still reachable as tooltips).

Every minimum size is derived from the widgets’ own minimumSizeHint() instead of a fixed pixel number, because the default UI font is materially wider on Windows than on macOS. The August 2026 commits (a81a1f5 through 66b0438) were a sequence of fixes for exactly this: controls clipped under larger system fonts.

5.6 Styling

The look comes from one Qt stylesheet, app/assets/styles/app.qss: a neutral dark palette (#0D0D0F window, #161618 cards, #0A84FF accent) documented in its header. Two rules keep it working:

  • No inline stylesheets on containers. A widget-level stylesheet overrides the application stylesheet for that widget and all of its children, which “silently strips the background from all the cards”. The rule is stated in the output_panel.py docstring and enforced by test_sidebar_containers_carry_no_inline_stylesheet.
  • Absolute asset URLs. Qt resolves url() in a stylesheet against the working directory, not the .qss file. app/ui/style.py replaces an @ASSETS@ placeholder with the real assets path at load time, so the dropdown chevrons appear both in development and inside a bundle.
