1 Project Overview

1.1 What SetupTTS does

SetupTTS turns text into an MP3 file using Microsoft’s neural voices, the same voices behind “Read Aloud” in the Edge browser. You paste text or open a .txt file, pick one of roughly three hundred voices, set a speed, choose a file name, and press Generate & Export MP3. A paragraph comes back in seconds. A full book runs in the background for hours, shows its progress, and can be stopped and resumed later, even after the app has been closed.

The README states the goal in one line: a desktop app “built to finish 12-hour audiobooks without silently losing a sentence”. That second half is the real subject of this book.

1.2 The problem it actually solves

Calling a speech service is easy. The edge-tts library does it in a few lines. The hard part is making a multi-hour job over an unreliable connection come out complete. The service accepts a few thousand bytes of text per request, so a book becomes a few hundred requests. Any of them can time out, return no audio, or, worst of all, stop early without reporting an error. A program that simply concatenates whatever comes back will eventually hand you an audiobook with a missing page in chapter 14 and no way to know.

SetupTTS treats every one of those failures as a normal event. It records exactly which characters of the source text each saved piece of audio covers, refuses to assemble the final file unless those pieces cover the whole text, and checks that the finished audio is plausibly as long as the text implies. If it cannot prove the file is complete, it does not write it under your name.

1.3 Who it is for

The design point is a single person producing long narration on an ordinary computer: an audiobook from a public-domain novel, a long article to listen to, study notes, a script in a language they are learning. The user is not expected to know what a WebSocket is. That is why so much of the code turns raw failures into plain sentences and why nothing in the normal workflow needs a terminal.

1.4 The main workflow

  1. Add text. Type, paste, use Open File… (Ctrl/Cmd+O), or drag a .txt or .md file onto the editor.
  2. Choose a voice. Filter by language and gender or search by name; Preview Voice plays a short sample. A warning appears if the voice does not suit the text’s language or script.
  3. Set the speed. A slider from -50 % to +100 %, with a Reset button.
  4. Export. Choose a file name and folder, then Generate & Export MP3 (Ctrl/Cmd+Enter).
  5. Watch or walk away. The Active Jobs card shows stage, percentage, chunk count, speed and, once it is reliable, time left. Finished files appear in Recent Conversions.

1.5 Platforms, provider and network

Question Answer at v1.6.2
Desktop platforms macOS 15 or later on Apple Silicon; Windows 10 and 11, 64-bit. Linux runs from source but has no packaged build.
Speech provider One: Microsoft’s online neural TTS service at speech.platform.bing.com, reached through the edge-tts library. There is no offline engine and no second provider.
Account or API key None. The service is used the way the Edge browser uses it, without an official API agreement, so its availability can change.
Internet Required for generation and for refreshing the voice list. Text preparation, verification and file writing are local.
Output format 24 kHz, 48 kbit/s mono MP3, the format the service streams.

Verified by runtime experiment. The live voice catalogue fetched while preparing this book listed 322 voices across 142 locales and 75 languages; 12 of them were “Multilingual” variants. The README’s “300+ voices in 70+ languages” is accurate for this date.
