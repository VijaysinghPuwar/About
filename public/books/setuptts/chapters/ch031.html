Appendix C: Glossary

Atomic replace. Writing a new file under a temporary name and renaming it over the target, so readers see the old or the new file and never a mixture.

Back-off. Waiting before retrying; exponential back-off doubles the wait each time (2, 4, 8, 16 s here).

CBR. Constant bit rate. Every second of audio is the same number of bytes (6,000 for 48 kbit/s), which lets SetupTTS convert bytes to seconds exactly.

Chunk. One unit of synthesis: a range of the cleaned text sent as one provider request and saved as one chunk_NNNNNN.mp3.

Coverage. Whether the saved chunk ranges tile the whole text with no gaps or overlaps.

edge-tts. The open-source Python client for the speech service used by the Edge browser’s Read Aloud.

Fail closed. On an unrecoverable error, stop without producing output that cannot be vouched for.

fsync. A system call asking the operating system to flush a file’s data to the storage device.

Job. One export: a text, a voice, a rate and an output path, with its own worker and staging folder.

Manifest. manifest.json in a job’s staging folder: job metadata plus one record per saved chunk.

Multilingual voice. A voice whose ShortName contains “Multilingual”; it can read mixed-language text but is treated as riskier for long English jobs.

onedir / onefile. PyInstaller output shapes: a folder of files, or a single executable that unpacks itself at launch.

Payload size. The UTF-8 byte length of a chunk after edge-tts’s own character filtering and XML escaping; the limit that usually decides chunk size.

Preflight. Checks before the first chunk: voice catalogue, compatibility, a startup synthesis, disk space.

Queued connection. A Qt signal-slot connection where the slot runs later on the receiver’s thread; used automatically across threads.

Recovery split. Dividing a repeatedly failing chunk’s range into smaller sub-ranges that exactly cover it.

Self-test. --selftest mode of the packaged app, used by CI to check assets, TLS, the UI and, with --network, live synthesis.

SentenceBoundary. edge-tts metadata event giving a sentence’s text, start offset and duration in 100-nanosecond ticks.

Staging folder. staging/<job_id>/: the job’s source text, manifest and chunk files until completion.

Trusted prefix. On resume, the chunks from index 0 up to the first invalid record; everything after it is regenerated.

WAL. SQLite’s write-ahead log mode, which lets readers and a writer work concurrently.
