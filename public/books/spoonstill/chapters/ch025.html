20 Learning Rust Through spoonstill

Every concept below is tied to real code in this repository. The project uses Rust edition 2024 with toolchain 1.94.0, pinned in rust-toolchain.toml.

20.1 Crates, modules and the workspace

Meaning. A crate is one compilation unit: a library or a binary. A module is a namespace inside a crate (one .rs file, or a folder with mod.rs). A workspace builds several crates together with one Cargo.lock.

Where. The root Cargo.toml declares members = ["crates/*", "apps/desktop"], shared metadata (version = "0.1.19", edition = "2024"), shared lints, and the internal crates as [workspace.dependencies]. Each crate opts in with version.workspace = true and [lints] workspace = true. crates/spoonstill-app/src/import/ is a module folder with mod.rs, rows.rs and settings.rs.

Why here. Crates give compiler-enforced boundaries: spoonstill-core literally cannot call process code because it has no dependency that provides it.

20.2 Ownership, borrowing and references

Meaning. Every value has one owner; when the owner goes out of scope, the value is dropped. You can lend a value as a shared reference &T (many readers) or a mutable reference &mut T (one writer), and the compiler checks lends never outlive the owner.

Where. Request<'a> in spoonstill-tts holds text: &'a str and voice: &'a str: it borrows the narration instead of copying it, so asking for 500 lines allocates nothing. Builder methods like FfmpegCommand::arg(&mut self, ...) -> &mut Self borrow the builder mutably and hand the borrow back, which is what makes .arg(a).arg(b) chains work.

// crates/spoonstill-tts/src/lib.rs:48-53
#[derive(Debug, Clone, Copy)]
pub struct Request<'a> {
    pub text: &'a str,
    pub voice: &'a str,
    pub settings: &'a [(String, String)],
}

Moving ownership. Partial::move_into_place(mut self, to) takes self by value: after calling it, the caller no longer has the guard, so it cannot be used twice.

20.3 String versus &str, PathBuf versus &Path, OsString

Meaning. String and PathBuf own their data and can grow; &str and &Path are borrowed views. OsString and &OsStr hold whatever bytes the operating system allows, which may not be valid UTF-8.

Where. Functions take &Path and store PathBuf (RealPath::real_path(&self, path: &Path) -> Option<PathBuf>). FfmpegCommand stores Vec<OsString> and accepts impl AsRef<OsStr>, so a file name that is not valid UTF-8 still reaches FFmpeg intact; a test pins this signature.

20.4 Option and Result

Meaning. Option<T> is Some(value) or None. Result<T, E> is Ok(value) or Err(error). Rust has no exceptions and no null; these types force you to handle absence and failure.

Where. parse_f64 in probe.rs returns None for N/A or non-finite values, so a missing duration is None, never 0 ("A zero here would become a one-frame segment"). Nearly every operation returns Result.

Combinators chain these without nesting:

// crates/spoonstill-core/src/project.rs:946-951 (shape)
draft.voice.as_deref().map(str::trim).filter(|v| !v.is_empty())
    .map_or_else(|| default_voice.clone(), |v| VoiceId(v.to_owned()))

Read it as: take the cell if present, trim it, ignore it if empty, otherwise use the project default.

20.5 Error propagation with ?

Meaning. expr? returns the error early if expr is Err, otherwise unwraps the Ok. If the error types differ, ? calls From::from to convert.

// crates/spoonstill-media/src/probe.rs:329
let finished = command.spawn()?.wait_until(timeout)?.ok()?;

Three fallible steps in one line. impl From<GeometryError> for MediaError and impl From<MediaError> for TtsError let ? cross crate error types automatically.

20.6 Enums with data, and pattern matching

Meaning. A Rust enum can carry different data in each variant. match must handle every variant, so adding one forces every match to be updated.

Where. AudioSource { Tts {..}, File {..}, Silent {..} }, ProblemKind (22 variants), FilmEvent, MediaError, the CLI's Command. Match guards appear in the probe retry:

// crates/spoonstill-media/src/probe.rs:296-304
fn with_retries<T>(mut attempt: impl FnMut() -> Result<T, MediaError>)
    -> Result<T, MediaError>
{
    let mut tries = 0;
    loop {
        match attempt() {
            Err(MediaError::Timeout { .. }) if tries < PROBE_RETRIES => tries += 1,
            outcome => return outcome,
        }
    }
}

Edition 2024 adds let chains, used throughout: if let Some(x) = earliest && x > now { ... } (pace.rs). And let-else: let Some(item) = items.get(index) else { return }; (pool.rs).

20.7 Structs, newtypes and encapsulation

SceneId(String) wraps a String with a private field and a validating constructor, so an invalid id cannot exist. OutputSpec has private fields and only OutputSpec::new, so every OutputSpec in the program is a legal frame size. Cancel(Arc<AtomicBool>) gives a shared flag a name and a small API.

20.8 Traits and trait objects

Meaning. A trait is a set of methods a type promises. dyn Trait is a trait object: a pointer to some value of an unknown concrete type that implements the trait, called through a table of function pointers.

Where.

  • Provider (TTS): providers() returns Vec<Box<dyn Provider>>.
  • MediaCheck (probing): &dyn MediaCheck lets validation run with real ffprobe, with SkipProbe, or with the window's memoizing RememberedProbe.
  • RealPath (core): keeps filesystem access out of core and lets tests use a fake disk.
  • Diagnostics (logging): Journal, FileLog and ActivityLog all implement it; the media crate records events without knowing where they go.
  • Standard traits: impl fmt::Display for MediaError, impl std::error::Error, impl Drop for Partial, impl Default.

Supertraits and default methods. pub trait Provider: Send + Sync requires every provider to be thread-safe. default_voice and install have default bodies.

20.9 Generics and closures

Meaning. Generics write one function for many types; trait bounds say what those types must support. Closures are anonymous functions that can capture variables.

Where. The worker pool is generic over the item, result and work:

// crates/spoonstill-app/src/pool.rs:134 (signature, abridged)
pub fn run<T: Sync, R: Send, F: Fn(usize, &T) -> R + Sync>(
    items: &[T], jobs: usize, cancel: &Cancel, work: F,
) -> Vec<Outcome<R>>

T: Sync because many threads read the items; R: Send because results move between threads; F: Fn + Sync because many threads call the same closure. impl FnOnce(&Path) -> Result<String, MediaError> lets ImageHashes::of accept "how to read a file" from its caller, so tests can count reads. fn(&str) -> bool (a plain function pointer) passes "is this file ours?" into the shared cache sweep.

20.10 Iterators

Chains like zip, filter_map, partition, max_by_key, find and collect replace manual loops. In ingest::assign, files are split into those that may be paired by position and those that may not with .partition(|path| may_guess(path)).

20.11 Concurrency: threads, atomics, mutexes, condition variables, channels

The project uses no async runtime in its core (the desktop app uses Tauri's runtime only at the edge). The unit of work is a child process that runs for seconds, so plain threads are simpler.

  • Scoped threads. std::thread::scope (in pool.rs) lets worker threads borrow the caller's data; the scope joins every thread before it returns, so no Arc or 'static bound is needed.
  • Atomics. AtomicUsize::fetch_add hands out work indices without a lock; AtomicBool is the cancel flag and the "stage one failed" flag; static WRITER: AtomicU64 makes temporary file names unique.
  • Mutex and Condvar. pipeline hands stage-one results to stage-two workers through a Mutex<Handoff> and a Condvar; a waiting worker sleeps until notified. The TTS Gate uses the same pair.
  • Channels. std::sync::mpsc carries FFmpeg progress from a reader thread to the waiting loop.
  • Lazy globals. OnceLock creates the process-wide TTS gate and the per-key lock map on first use, without unsafe.
  • Poison recovery. .lock().unwrap_or_else(PoisonError::into_inner) keeps working after another thread panicked while holding a lock.

20.12 RAII and Drop

Meaning. A value can run code when it is dropped. That makes cleanup automatic and impossible to forget, even on an early ? return or a panic.

Where. Partial deletes a temporary unless the rename succeeded; Captions deletes caption band files; Scratch deletes TTS pieces; Slot frees a TTS pace slot; Lock releases the render lock; ActiveRender (desktop) frees the window's render slot. D-115 and D-178 are both bugs where cleanup written as "a statement after the work" was skipped by ?.

// crates/spoonstill-media/src/atomic.rs:220-226
impl Drop for Partial {
    fn drop(&mut self) {
        if !self.keep {
            let _ = std::fs::remove_file(&self.path);
        }
    }
}

20.13 Serialization with serde

#[derive(Deserialize)] with #[serde(deny_unknown_fields)] turns project.yaml (via serde_yaml_ng) and scenes.csv (via csv) into structs and rejects typos. serde_json parses ffprobe's output. In the desktop app, #[derive(Serialize)] turns Rust views into JSON for the page, and #[serde(tag = "kind", rename_all = "camelCase")] produces {"kind":"segment", ...} progress messages.

20.14 Process spawning and the filesystem

std::process::Command with piped stdio (Chapter 16); std::fs::rename (atomic replace on macOS and Windows); OpenOptions::new().create_new(true) to claim a name only if it does not exist; File::try_lock and File::lock (stable since Rust 1.89) for the render lock and runs.csv; std::fs::canonicalize for path containment.

20.15 Conditional compilation

#[cfg(windows)], #[cfg(target_os = "macos")], cfg!(windows) as an expression, #[cfg(test)] mod tests in every file, #![cfg(unix)] for a whole test file, and #[cfg_attr(not(windows), allow(dead_code))] so a Windows-only helper does not trigger a warning-as-error on macOS. The project's rule: compile both platform variants on every platform where possible, so tests for Windows quoting run on a Mac.

20.16 Lints and attributes

#[must_use] on pure functions, #![warn(missing_docs)] in the libraries, targeted #[allow(clippy::cast_precision_loss)], and at workspace level unsafe_code = "forbid" and clippy::all = "deny".
