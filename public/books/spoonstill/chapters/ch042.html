35 Glossary

AAC. Advanced Audio Coding, the compressed audio format in the final MP4 (AAC-LC, 192 kb/s).

Anchor. In spoonstill, the fixed point of a zoom or the cross-axis position of a pan (Center, North, SouthEast, ...).

Artifact (CI). A file produced by a build, such as still-Windows.zip.

Aspect ratio. The frame's shape: 16:9, 9:16 or 1:1.

Atomic rename. Replacing a file in one filesystem operation so readers see the old or the new file, never a partial one.

Bitrate. Bits per second of a compressed stream.

Cache key. A hash of everything that affects an artifact's bytes; the artifact's file name.

Checksum (SHA-256). A fingerprint of a file; if one byte changes, the checksum changes. Used to verify downloads.

Child process. A program started by another program. spoonstill runs FFmpeg, ffprobe and edge-tts as child processes.

CI. Continuous integration: automated checks on every push (GitHub Actions here).

Codec. A method of compressing audio or video (H.264, AAC).

Concat demuxer. FFmpeg's way of reading a list of files as one input; with -c copy it joins without re-encoding.

Condition variable (Condvar). Lets a thread sleep until another thread signals that something changed.

Container. A file format holding streams and timing (MP4).

Cover-fit. Scaling an image so it covers a box completely, cropping the overhang (as opposed to fitting inside with borders).

Crate. A Rust compilation unit (library or binary).

CRF. x264's constant rate factor: lower is higher quality.

Cue. One caption shown for a time range.

Demux / mux. Taking streams out of a container / putting them in.

Edge TTS. Microsoft Edge's "Read Aloud" neural voices, used through the edge-tts tool.

enum. A Rust type with several variants, each optionally carrying data.

Exit code. A number a process returns when it ends; 0 usually means success.

ffprobe. FFmpeg's companion program that reports facts about a media file.

Filter graph. A network of FFmpeg filters connected by labelled pads.

FNV-1a. A small, fast, stable non-cryptographic hash used for cache keys.

Frame / frame rate. One picture of a video / pictures per second.

H.264. The video codec used (also called AVC); profile High, level derived.

Ken Burns effect. Slow pan and zoom over a still image.

Key frame. A frame stored completely, not as a difference from others.

Level (H.264). A label for the decoder workload a stream needs, derived from frame size and rate.

LUFS. Loudness Units relative to Full Scale, a measure of perceived loudness.

Manifest. scenes.csv, an explicit list of scenes.

Mutex. A lock that lets one thread at a time access shared data.

Newtype. A struct wrapping one value to give it a distinct type and rules (SceneId(String)).

Option / Result. Rust types for "maybe a value" and "a value or an error".

PCM. Uncompressed audio samples; the cache's WAVs are 16-bit PCM.

Pixel format. How pixels are stored; spoonstill outputs yuv420p.

Prescale canvas. The 3x-sized image the window moves over.

Profile (segment). The full set of properties every segment must have; checked with ffprobe.

RAII / Drop. Cleanup tied to a value's lifetime, run automatically when it goes out of scope.

Remedy. spoonstill's data shape for "a tool is missing, here is the fix".

Sample rate. Audio samples per second (48 000 here).

SAR. Sample aspect ratio: the shape of one pixel. Must be 1:1.

Scene. One still plus its narration (or silence), rendered as one segment.

Segment. One scene rendered to an MP4 file in the cache.

Shell injection. When text meant as data is interpreted as commands by a shell.

Single-flight. Ensuring concurrent requests for the same work do it once.

Stream copy. Copying compressed packets without decoding (-c copy).

Time base. The unit timestamps are counted in (1/90000 for video here).

Trait / trait object. A set of methods a type promises / a pointer to "some type implementing this trait".

TTS. Text-to-speech.

Workspace. Several Rust crates built together.

yuv420p / tv range / BT.709. The pixel format, colour range and colour standard spoonstill pins for every segment.
