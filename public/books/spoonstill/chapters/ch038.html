32 Limitations, Technical Debt and Future Areas

32.1 Current limitations (true of the code at this commit)

  • Hard cuts only; no fades or dissolves (D-057 accepted, not built).
  • One TTS provider (Edge through edge-tts), an unofficial service with a 24 kHz mono quality ceiling and a throttle; no API-key provider, no key storage.
  • No state.db or per-project reporting index; history is in the logs.
  • FFmpeg is not bundled; the operator installs it.
  • Builds are unsigned and not notarized; no auto-updater.
  • The licence for spoonstill's own code has not been chosen ("all rights reserved").
  • Captions draw Latin, Greek, Cyrillic and Devanagari; other scripts show boxes (validation names them).
  • 4K is the maximum output size.
  • Hardware encoding is an explicit draft mode; VideoToolbox is unmeasured.
  • Old projects (no motion_seed) re-encode every scene when reordered unless switched to v2.
  • Two separate copies of one photo at different paths get the same V2 motion.
  • No GUI automation; window behaviour is tested at its seams.
  • The window has no single-scene motion preview (the CLI has render-scene).
  • Linux is not a release target.
  • Rust dependency licence notices are not generated.

32.2 Documentation drift found while preparing this book

These are places where documents disagree with the code at this commit (all verified by reading or grep). They are not bugs in behaviour, but they will mislead a reader:

  • spoonstill-state/src/lib.rs describes a SQLite state machine that does not exist; spoonstill-tts/src/lib.rs describes ElevenLabs and keyring-rs, which do not exist.
  • film.rs's module comment describes separate audio and render phases (they overlap since D-146).
  • pool::SEGMENT_MEMORY_BYTES is unused.
  • rows.rs lists seven manifest columns; the code accepts eight.
  • captions.rs says the renderer uses between(); it uses gte(t,S)*lt(t,E).
  • ci.yml still says make gates is "29 checks" (it is 39); release.yml says "three jobs" and "twelve assets" (four and ten).
  • apps/desktop/Cargo.toml says architecture.rs checks the desktop's dependencies; it does not.
  • plan.md still names FFmpeg 8.0.1 as installed and uses a --verbose flag that does not exist.
  • The README's per-crate line table is stale (only spoonstill-state matches), though its total is checked by a test.
  • .cargo/audit.toml says three fonts are embedded (there are six).
  • A string literal in the CLI's unknown-subtitle-theme message contains about 22 stray spaces.
  • There are no TODO, FIXME, todo!() or unimplemented!() markers in tracked files; open work is tracked in decisions.md and plan.md instead.

32.3 Planned (in plan.md or the README roadmap)

  1. Split one long recording on silence into one piece per photo (described as the biggest remaining saving).
  2. A higher-fidelity, bring-your-own-key TTS provider (ElevenLabs).
  3. Transitions, after xfade is measured at 500 scenes.
  4. state.db as a reporting index (not for resume).
  5. M5 packaging: an LGPL FFmpeg build, bundled and checksum-verified; signing; notarization; an updater; a generated licence manifest.
  6. From D-193's list: a style note and "Copy for Google Flow"; a placeholder so a scene waiting for a picture can render; deciding whether to speak a whole chapter once and cut it at word boundaries.

32.4 Open questions

  • D-072: word-level karaoke captions from provider word boundaries.
  • The real throttle threshold of the Edge service (the pace gate is "a margin, not a measurement").
  • Concatenating segments on a Windows network (UNC) share has not been tested.

32.5 Historical ideas (recorded, not committed to)

A frame-server architecture if motion ever outgrows FFmpeg filters (D-060); scale plus crop as a fallback if zoompan regresses (D-031); an SRT sidecar file; an Azure voice provider (explicitly not built by the author's choice); a music bed and limiter; renaming the vidio/ folder.

32.6 Possible improvements suggested by this review (the author's call, not project commitments)

  • Extend architecture.rs to read apps/*/Cargo.toml so the desktop's dependency rule is enforced, as its manifest claims.
  • Rename or document the spoken field in the film complete log row, which counts every non-reused narration, not only spoken ones.
  • Make an in-flight cancellation on the final TTS retry surface as Cancelled rather than a network error.
  • Bring the stale module comments listed above in line with the code.
