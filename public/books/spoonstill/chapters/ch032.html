27.3 What these dependencies save

Without clap, every one of fifteen subcommands would need hand-written parsing and help. Without serde, three file formats and one IPC protocol would need hand-written readers. Without fontdue and harfrust, captions would need FFmpeg builds the operator does not have. Without Tauri, the window would need a native UI toolkit per platform. Equally telling are the dependencies not taken: no FFmpeg bindings, no async runtime in the core, no HTTP client, no SQLite, no date or directory-finding crate (a 20-line config_dir and a hand-written UTC formatter replace them).
