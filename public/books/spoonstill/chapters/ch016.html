12 Tracing Everyday Operations

This chapter follows four ordinary commands from the moment you press Enter to the moment the terminal prompt returns. The render is big enough to get its own chapter (Chapter 14).

Two facts worth remembering. First, nothing is moved or modified in your source folder; everything is copied. Second, create_project writes project.yaml only when no such file exists, so re-running it can never overwrite your settings.

12.2 Adding files: still add DIR FILE...

add is add_media alone. It numbers new photos after the highest existing number, so files are never overwritten. If a scene is waiting for a picture (a numbered .txt with no image, created by import-chapter), the new photo fills it, and the report says which scenes it filled.

12.3 Validating: still validate DIR

validate(args)                                    main.rs:1200
  media = ProbeCheck::from_env()   (or SkipProbe with --no-probe)
  spoonstill_app::import::load(&dir, media, &Cancel::new())
     1. canonicalize root; must be a directory          -> ImportError::NoProject
     2. settings::load: project.yaml <= 1 MiB, unknown keys rejected,
        each value validated (aspect, resolution XOR short_edge, fps, crf...)
     3. rows::collect: manifest, scenes.csv, or folder convention
     4. media.ready(): is ffprobe runnable at all?  one ToolingMissing if not
     5. core::validate_drafts: exactly one audio source per scene, ids, zoom words
     6. pool::run over rows (probe_jobs = 2 x default jobs):
           resolve_within(root, path)  -> Problem::Path if outside
           ffprobe the still (geometry) and the recording (duration)
     7. warnings: unlisted images, undersized stills, undrawable caption characters,
        scenes waiting for pictures
     8. order problems: project first, then by scene
  print scenes and problems
  Ok if only warnings; Err("N problems in DIR (M warnings)") if any error -> exit 1

Validation reads only. It never creates .spoonstill/ in a folder that does not have one, and Ctrl-C ends it immediately.

12.5 Voices: still voices [FILTER] [--use NAME] [--forget] [--install]

list_voices()                                     main.rs:1076
  --forget: machine::set_default_voice(None) BEFORE asking the provider anything
  provider = tts::provider("edge")
  availability(); if missing and --install: provider.install()
  voices(): edge-tts --list-voices (retried like speech), parsed from its table
  --use NAME: checked against the catalogue when there is one, then saved to
              settings.yaml as the machine's fallback voice
  print voices matching FILTER, marking the fallback with *

--forget runs before any network call so an operator with no internet can still undo a setting that is failing them (D-168).
