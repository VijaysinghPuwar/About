38 A 15-Video Learning Curriculum

Every video below was checked on 2026-10-07: its title and channel were read from YouTube's oEmbed endpoint, and its duration from the lengthSeconds field of its watch page. The descriptions are based on titles, channel and search results, not on watching every minute. Two titles contain a crab emoji, written here as [crab emoji]. The oEmbed check was repeated immediately before this book was generated, and all 18 links (15 plus 3 extras) answered.

38.1 The videos

1. Rust in 100 Seconds. Fireship. https://www.youtube.com/watch?v=5C_HPTJg5ek. 2:29. Beginner. Why it matters: a one-screen orientation to what Rust is and why it is used for tools like spoonstill. Focus on: memory safety without a garbage collector; Cargo. Watch before: Chapter 20. Files: Cargo.toml, rust-toolchain.toml.

2. Rust for the impatient. No Boilerplate. https://www.youtube.com/watch?v=br3GIIQeefY. 10:42. Beginner. Why: a fast syntax tour so code excerpts read naturally. Focus on: enums, match, Option, Result. Watch before: Chapter 5. Files: crates/spoonstill-core/src/project.rs.

3. Understanding Ownership in Rust. Let's Get Rusty. https://www.youtube.com/watch?v=VFIOSWy93H0. 25:30. Beginner. Why: ownership and borrowing explain &Path vs PathBuf, Request<'a>, and why move_into_place(self) consumes its guard. Focus on: moves, references, borrowing rules. Watch before: Chapter 20. Files: crates/spoonstill-tts/src/lib.rs, crates/spoonstill-media/src/atomic.rs.

4. Rust Linz, January '22 - Error Handling in Rust - A Pragmatic Approach by Luca Palmieri. Rust Programming Language (official). https://www.youtube.com/watch?v=jpVzSse7oJ4. 33:40. Intermediate. Why: spoonstill's error design (typed errors per crate, From conversions, operator-facing Display) follows the same principles. Focus on: when to use enums for errors; context. Watch before: Chapter 21. Files: crates/spoonstill-media/src/error.rs, crates/spoonstill-app/src/film.rs (FilmError).

5. Structuring larger Rust projects with Cargo Workspaces. Let's Get Rusty. https://www.youtube.com/watch?v=S3c7NRS698A. 6:06. Beginner. Why: spoonstill is a seven-member workspace. Focus on: members, path dependencies, shared settings. Watch before: Chapter 4. Files: root Cargo.toml, each crate's Cargo.toml.

6. Understanding Mutexes and Thread Safety in Rust. Ardan Labs. https://www.youtube.com/watch?v=6Qg84mkSQv8. 11:16. Intermediate. Why: the render pool, single-flight caches and the TTS gate are built from Mutex, Arc and atomics. Focus on: Arc<Mutex<T>>, why Send/Sync exist. Watch before: Chapter 9 (pools). Files: crates/spoonstill-app/src/pool.rs, crates/spoonstill-tts/src/pace.rs.

7. Spawn External Processes with Rust Standard Library [crab emoji] Rust Programming Tutorial for Developers. Trevor Sullivan. https://www.youtube.com/watch?v=RtVzlk4om6U. 54:06. Intermediate. Why: std::process::Command is how spoonstill runs FFmpeg, ffprobe and edge-tts. Focus on: arguments as a list, piping stdout and stderr, waiting for exit. Watch before: Chapter 16. Files: crates/spoonstill-media/src/command.rs.

8. Write Unit Tests in Rust [crab emoji] Rust Programming Tutorial for Developers. Trevor Sullivan. https://www.youtube.com/watch?v=0G_5uUe_NXk. 36:29. Beginner. Why: 776 test functions; reading them is one of the best ways to learn the code. Focus on: #[test], #[cfg(test)], running a subset. Watch before: Chapter 25. Files: any mod tests, crates/spoonstill-media/tests/.

9. FFmpeg in 100 Seconds. Fireship. https://www.youtube.com/watch?v=26Mayv5JPz0. 2:20. Beginner. Why: the shape of an ffmpeg command line: inputs, options, outputs. Focus on: -i, codecs, output file. Watch before: Chapter 3. Files: crates/spoonstill-media/src/scene.rs.

10. FFMPEG & Filter Complex: A Visual Guide to the Filtergraph Usage. Dev Stef. https://www.youtube.com/watch?v=Yc16I6i9xDU. 24:53. Intermediate. Why: the Ken Burns chain, the audio chain and caption overlays are one -filter_complex graph. Focus on: labelled pads like [0:v] and [v], chaining with commas and semicolons, multiple inputs. Watch before: Chapter 15. Files: crates/spoonstill-core/src/motion.rs, scene.rs (Captions::graph).

11. Explaining Digital Video: Formats, Codecs & Containers. ExplainingComputers. https://www.youtube.com/watch?v=-4NXxY4maYc. 14:43. Beginner. Why: separates the container (MP4) from the codecs (H.264, AAC). Focus on: what is inside an MP4. Watch before: Chapter 3. Files: crates/spoonstill-media/src/profile.rs.

12. How video compression works. Elecard. https://www.youtube.com/watch?v=QETZ6MO2QX0. 10:48. Intermediate. Why: explains key frames and predicted frames, which is why segments must start on a key frame and share parameters to be stream-copied. Focus on: I/P/B frames, motion prediction. Watch before: Chapter 15 (joining). Files: crates/spoonstill-media/src/concat.rs.

13. Audio Bit Depth and Sample Rate Explained. iZotope, Inc. https://www.youtube.com/watch?v=xJKypZXc3B4. 6:14. Beginner. Why: spoonstill's intermediate audio is 16-bit, 48 kHz PCM and its trims count samples. Focus on: what a sample is; why 48 kHz. Watch before: Chapter 17. Files: crates/spoonstill-media/src/audio.rs, crates/spoonstill-core/src/timing.rs.

14. Tauri v2 And Why You Should Pay Attention. Jacob Bolda. https://www.youtube.com/watch?v=skMhbFIU9vw. 9:09. Intermediate. Why: the desktop app is Tauri 2: a Rust process with a web view, permissions defined as capabilities. Focus on: commands, capabilities, plugins. Watch before: Chapter 11. Files: apps/desktop/src/main.rs, apps/desktop/capabilities/default.json.

15. How to use GitHub Actions | GitHub for Beginners. GitHub (official). https://www.youtube.com/watch?v=BQrohJ3PT7I. 8:04. Beginner. Why: CI and releases are GitHub Actions workflows. Focus on: triggers, jobs, runners, steps. Watch before: Chapter 26. Files: .github/workflows/ci.yml, release.yml.

Optional extras, also verified: Tauri in 100 Seconds (Fireship, https://www.youtube.com/watch?v=-X8evddpu7M, 2:40; predates Tauri 2, concepts only); Why Snow and Confetti Ruin YouTube Video Quality (Tom Scott, https://www.youtube.com/watch?v=r6Rp-uo6HmI, 4:20); What is LUFS and why is it important? (The Audio Professor, https://www.youtube.com/watch?v=s7dwnFqMhI8, 2:13). No good explanatory video about the Ken Burns technique itself was found; Chapter 15 covers it.

38.2 A learning order

Stage 1: Rust foundations (about 38 minutes). Videos 1, 2, 3. Afterwards you should understand: ownership, borrowing, Option, Result, enum and match, enough to read Chapters 5 and 20.

Stage 2: Rust as a project (about 1 h 16 min). Videos 5, 4, 8. Afterwards: how a workspace splits into crates, how errors flow upward with ? and From, and how to run and read tests. Read Chapters 4, 21 and 25.

Stage 3: media fundamentals (about 32 minutes). Videos 11, 12, 13 (plus the snow-and-confetti and LUFS extras). Afterwards: containers versus codecs, key frames, samples and loudness. Re-read Chapter 3.

Stage 4: driving FFmpeg from Rust (about 1 h 33 min). Videos 9, 10, 7, 6. Afterwards: read the segment command in Chapter 15 argument by argument, follow command.rs, and understand how the pool runs several FFmpegs safely.

Stage 5: shipping it (about 17 minutes). Videos 14, 15. Afterwards: follow a Render click through Tauri (Chapter 11) and a tag through the release workflow (Chapter 26).
