34 A Code Reading Guide

Read in this order. Each level builds on the previous one.

Level 1: the product. README.md (quickstart, how a project folder works, the size table); then run the commands in Chapter 2. Why: everything else is easier when you have seen a render.

Level 2: the vocabulary. crates/spoonstill-core/src/lib.rs, project.rs (types first, then validate_draft), geometry.rs (OutputSpec::new), timing.rs. Why: these types appear in every other crate.

Level 3: the motion. crates/spoonstill-core/src/motion.rs, especially build_filter, progress_expr, axis_expr, and the test that pins the string. Pair it with Chapter 15. Why: this is the heart of the visual result.

Level 4: the process boundary. crates/spoonstill-media/src/command.rs (FfmpegCommand, spawn, wait_until, Cancel), then tools.rs (locate), probe.rs, profile.rs. Why: every interaction with the outside world goes through here.

Level 5: one scene. crates/spoonstill-media/src/scene.rs (render_scene_inner, run_ffmpeg, validate), audio.rs (normalize, gain_db, silence, measure), atomic.rs. Then try still render-scene. Why: this is M1, the whole product in miniature.

Level 6: a project. crates/spoonstill-app/src/import/mod.rs (load), import/rows.rs (from_convention), import/settings.rs; then film.rs (render_project, resolve_and_render, plan_scene, segment_key, render_one, prune); then pool.rs and audio.rs; then concat.rs in media. Why: this is M2: caching, parallelism and the join.

Level 7: speech. crates/spoonstill-tts/src/lib.rs, edge.rs (speak, classify, persevere, split_line), pace.rs.

Level 8: the surfaces. crates/spoonstill-cli/src/main.rs (main, run, dispatch, render_project); then apps/desktop/src/main.rs (render_project, ActiveRender, view_of) alongside apps/desktop/ui/app.js (render, load, renderBlocker, drawFix).

Level 9: infrastructure. Makefile, scripts/m2-gates.sh (read a few gates), .github/workflows/ci.yml and release.yml, scripts/install.sh, crates/spoonstill-cli/tests/architecture.rs.

Level 10: the reasoning. decisions.md, starting with D-010, D-020 to D-022, D-030 to D-037, D-041, D-043, D-077, D-106, D-144, D-153 and D-154; then ffmpeg-findings.md §1 to §7 and §10 to §13.
